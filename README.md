# Heap Quest

A free practice game for the OCP Java SE 21 Developer exam (1Z0-830), then a timed 20-question mock exam drawn from a pool of 40.

Static site, no build step. Open `index.html` in a browser to play locally.

Progress is saved in each visitor's browser (localStorage).
