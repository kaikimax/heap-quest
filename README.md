# Heap Quest

A free practice game for the OCP Java SE 21 Developer exam (1Z0-830), covering Chapter 1: eight zones of lessons and challenges, then a timed 20-question mock exam drawn from a pool of 40.

Static site, no build step. Open `index.html` in a browser to play locally.

## Before you publish
Replace `kaikimax` with your GitHub username in `index.html`, `robots.txt` and `sitemap.xml`.
If your repo isn't named `heap-quest`, replace that part of the URL too.

## Publish on GitHub Pages
1. Upload every file in this folder to the root of your repo's `main` branch.
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch*, `main`, `/ (root)` → Save.
3. The site goes live at `https://kaikimax.github.io/heap-quest/`.
4. To get it indexed, add the site in Google Search Console and submit `sitemap.xml`.

Progress is saved in each visitor's browser (localStorage).
