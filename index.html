About Heap Quest

Heap Quest is a free practice game for the Oracle Certified Professional: Java SE 21 Developer exam (1Z0-830), organized chapter by chapter. Chapters 1 and 2 are playable now. They cover the object life-cycle and garbage collection, packages and imports, access modifiers, static and instance members, methods and pass-by-value, method overloading and varargs, constructors and initialization order, nested, inner, local and anonymous classes, variable scope and var, abstract classes, interfaces, sealed types, overriding, casting, pattern matching with instanceof and switch, and immutable objects.

Each zone has a short lesson, exam traps, and practice questions, including multi-select "choose two" questions like the real certification. Collect a fragment from every zone to unlock each chapter's timed Java 21 mock exam.
