About Heap Quest

Heap Quest is a free practice game for the Oracle Certified Professional: Java SE 21 Developer exam (1Z0-830), organized chapter by chapter. Chapter 1 is playable now and covers the object life-cycle and garbage collection, packages and imports, access modifiers, static and instance members, methods and pass-by-value, method overloading and varargs, constructors and initialization order, and nested, inner, local and anonymous classes.

Each zone has a short lesson, exam traps, and practice questions, including multi-select "choose two" questions like the real certification. Collect a fragment from every zone to unlock each chapter's timed Java 21 mock exam.
